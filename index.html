Project 1 - NotExo

An independent research initiative applying machine learning to open-access satellite data to advance planetary science and exoplanet research.

  • Investigated whether NASA's MAVEN MAG and Tianwen-1 MOMAG measurements can be combined to extend data coverage for vSWIM's Gaussian Process Regression, while preserving the existing GPR implementation.
  • Aligned overlapping MAG and MOMAG measurements using Theil–Sen regression to establish a common measurement scale.

  • Developed an interactive visualizer for the vSWIM model to track solar wind predictions, satellite orbits, and model uncertainty across MAVEN data gaps.

Project 2 - FissionMunk

An open-source Python library for two-dimensional nuclear fission simulations, built on Pymunk to provide reusable components for learning about nuclear reactor systems.

Built after researching nuclear fission and reactor operation, including neutron behavior, moderators, control rods, and coolant systems, to guide the development of an educational simulation.

Streams simulation states as JSON over WebSockets in real time, so external interfaces can visualize reactor behavior as the simulation runs. Demonstrated at DemoCamp.
